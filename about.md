# Process Difficulty

Create sections for a level, give each section a difficulty rating, and see the
current section while playing. You can manage local presets and share SectionData
and FlagData through the server map list.

This free distribution contains the same core gameplay features as the
membership distribution. Membership adds visual-element customization only.

## How to use

1. Open the pause menu in a level.
2. Select **Part Setting**.
3. Add each section at its starting percentage.
4. Assign a difficulty value from 0 to 100.

Use **Server Map List** to find presets shared by other players.
